Esta ação limpará todos os dados em cache na interface e recarregará a página. É útil para resolver problemas de visualização ou sincronia. Nenhum dado será apagado do banco de dados.

Atenção: Ação Irreversível.
Esta ação apagará todos os dados do sistema, incluindo produção, paradas, configurações e estoque. Recomenda-se fortemente fazer um backup na Central de Dados antes de continuar.
